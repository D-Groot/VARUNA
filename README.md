# VARUNA — Village AI-driven Real-time Utility Network Analysis

**Team:** Lazy Ants  
**SIH Problem Statement:** SIH26255  
**Ministry:** Ministry of Jal Shakti  
**Department:** National Jal Jeevan Mission

## 1. Problem
Rural tap-water services can experience interruptions, low pressure, leakage, and water-quality concerns. Periodic inspections and disconnected reports can delay identification and verification of incidents.

## 2. Proposed Solution
VARUNA is a proposed AI-assisted monitoring and decision-support platform that combines available service readings, citizen reports, and maintenance history to flag probable incidents and prioritize verification.

## 3. Objectives
- Identify unusual water-service patterns.
- Group related reports into potential incidents.
- Explain alerts using evidence, confidence, and data freshness.
- Prioritize verification using severity, duration, and affected households.
- Support low-connectivity reporting and synchronization.
- Prepare an integration adapter for authorized IMIS/Sujal Gaon ID workflows.

## 4. Intended Users
Gram Panchayats, Village Water and Sanitation Committees, field staff, and authorized water-supply administrators.

## 5. Prototype Scope
A software demonstration using clearly labelled sample or synthetic data. Real sensor deployment, field validation, and live government-system integration are not claimed unless completed.

## 6. Key Differentiator
VARUNA distinguishes a probable incident from a verified failure. Missing data is displayed as UNKNOWN, not NORMAL. Water potability is never inferred from a complaint or a single proxy measurement.

## 7. Limitations
Initial results may not represent actual village conditions. Operational deployment requires appropriate data access, field validation, privacy safeguards, and stakeholder approval.
